Total Participants: 51 unique subjects (408 reaching-sideways trials, 8 reps/subject)
Prediction Unit: 1 row per subject (no intra-subject data leakage)

3. RIGOROUS SUBJECT-WISE DATA PARTITIONING & LEAKAGE PREVENTION
Cross-Validation: 5-Fold Stratified Group Cross-Validation (StratifiedGroupKFold)
Subject Isolation: Exactly 0 subjects shared across train and test partitions (one row per subject, grouped splits)
Pipeline Encapsulation: Median Imputer, StandardScaler, and Mutual Information SelectKBest
                      fit ONLY on training folds inside each cross-validation iteration.
Temporal & Identifier Leakage: Subject IDs and metadata dropped; repetition trends computed strictly intra-subject.

7. KEY FINDINGS (generated from the results above):
- Top-3 by inner-validation accuracy: MLP, Extra_Trees, RBF_SVM; tree ensembles and a linear SVM are competitive, and differences among them are within one fold-SD.
- Repetition-aware descriptors did NOT show a statistically supported advantage over static per-subject means (accuracy 0.924 vs 0.942; ROC-AUC 1.000 vs 0.989; smallest FDR-adjusted Wilcoxon p = 1.00, n = 5 paired folds, i.e. under-powered). The claim that repetition-derived features add discriminative value is therefore not demonstrated for DCP-vs-TD classification on this dataset.
- Path-straightness features (path efficiency, lateral deviation) are the strongest univariate and model-based separators.

9d. HOW TO READ THE UNCERTAINTY NUMBERS:
- Fold SD (+/-): spread of 5 outer folds of ~10 subjects each; coarse (10-point steps), not a CI.
- Repeated-split variability (Table 3): re-partitions the SAME 51 subjects; shows sensitivity to the split only. Intervals are too narrow to be read as generalisation uncertainty.
- Bootstrap CIs on pooled out-of-fold predictions (Tables 1b, 2): resample the 51 subjects, so they reflect subject-sampling noise in the test predictions, but they hold the trained models fixed and (for Table 2) the model-family choice fixed; they do not include training-set or model-selection variability. Table 1b includes selection inside every fold but still not the variability of re-drawing a different training cohort.
- None of them measure generalisation to new sites, scanners, clinicians or populations: all data come from one dataset (site/acquisition confound unresolved).
- 'Final test' = outer cross-validation folds. There is NO independent hold-out or external test set (impossible with n = 51 without discarding ~20% of subjects).

10. LIMITATIONS
- n = 51 subjects (about 10 test subjects per fold): fold-level metrics move in ~10-point steps; report CIs/variance, not point values. All estimates are pilot-level.
- Acquisition confound: the supplied data contain no site/session/camera variable and subject-number blocks are structured by group (see results/confound_analysis/confound_summary.txt); the dataset paper describes per-lab DeepLabCut models, so recording setup cannot be separated from group effects. High accuracy may partly reflect recording setup; an independent, site-balanced cohort is needed.
- Pixel-to-mm conversion uses a fixed 2 mm/pixel (paper reports it is approximated from target size); absolute-length features are approximate.
- DCP-vs-TD is an easy, large-effect task; high scores do not imply clinical severity grading or generalisation to other populations.
- Model ranking by inner-CV accuracy is itself noisy at this n; the top-3 are statistically indistinguishable.
- No external test cohort and no independent hold-out set: nested subject-wise CV is the evaluation; recording-site/acquisition confounding remains UNRESOLVED (no site variable to adjust for; a subject-ID-only baseline already separates the groups).
