-- UNRESOLVED LIMITATIONS --
LIMITATION: Globally selected top-3 results are optimistic — The top-3 list pools inner-CV results over ALL outer folds, so each outer test subject sat in the training data of the other folds that produced the ranking. Outer-fold results of these 3 families (about 0.90 accuracy) are therefore optimistic validation numbers, NOT independent final-test performance. The unbiased estimate of the whole selection process is the fully nested one (results/nested_selection, headline).
LIMITATION: Recording-site / acquisition confounding — No site/session/camera variable exists in the supplied data (a per-site claim in earlier drafts could not be verified and was removed); subject-number blocks are structured by group, and file/subject numbering alone separates the groups (ID-only baseline in label_permutation_test.csv). A model could partly exploit acquisition differences; the permutation test cannot detect this. Unresolved.
LIMITATION: No independent test set / external cohort — n = 51 from one dataset. 'Final test' = outer cross-validation folds; generalisation to new children, sites or cameras is untested.
LIMITATION: Uncertainty intervals are conditional — Bootstrap CIs resample the same 51 subjects with trained models fixed; repeated CV re-partitions the same subjects. Neither includes cohort-level or site-level variability.
LIMITATION: Repetition-aware features — No statistically supported classification advantage over static means (5 paired folds, under-powered); FRI is a proposed, not clinically validated, index.
